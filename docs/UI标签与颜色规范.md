# UI 标签与颜色规范

本规范用于约束 Telance Records 的状态、元信息、短编号和颜色使用。页面新增信息时优先复用这里的语义，不再按页面单独创造 Tag 样式。

## 现状清单

| 页面 | 当前信息 | 表现与约束 |
| --- | --- | --- |
| 总览 | Ready、记录更新时间、记录计数、项目记录 Skill 路径 | Ready 只在未选择项目时作为眉题；更新时间、计数和 Skill 路径是普通辅助信息，不使用状态 Tag |
| 任务 | 短编号、优先级、工作等级、状态、列计数 | 列已经表达 Todo、Doing、Done；卡片不重复展示状态 Tag，详情中才显示完整状态 |
| 想法 | 短编号、Inbox / Done | 状态统一使用图标、文字和语义色 |
| 研究 | 短编号、研究模式、研究状态、关联记录 | 模式和关联记录属于元信息；待研究、进行中、已完成、已归档属于状态 |
| 版本 | 版本号、版本标签、当前版本或完成时间 | 版本标签是元信息；当前版本和完成时间使用普通状态文字，不使用 Tag |
| 协作 | 短编号、问题类型、阻塞提示、待跟进、风险、历史状态 | 问题类型和风险类型是分类；阻塞、待跟进、已完成、已处理、已归档按状态层级展示 |
| 工作记录 | 日志号、记录状态、记录等级、任务号、来源 | 目录默认隐藏 Done；详情可显示完整状态，记录等级和来源保持元信息样式 |
| 文档/知识库 | 出处、分类、关联记录 | 均为普通元信息，不借用状态色 |
| 约束 | 约束类型、来源 | 使用图标和文字；不额外制造状态 Tag |

## 当前色板

基础层使用中性黑灰和暖白，`#78461A` 是全局唯一品牌主色。语义色只用于状态，不使用蓝色背景、蓝色选中面或蓝色主按钮。

| 品牌主色/主操作 | `#78461A` | `#78461A` |

## Tag 规则

### 1. 短编号

`T113`、`L263`、`R041`、`V002` 只使用等宽辅助文字，不使用背景、边框或圆角。

### 2. 元信息

领域、来源、记录等级、研究模式、关联关系使用无底色的“图标 + 文字”。

- 分类/领域：Tag 图标。
- 记录等级：轻量使用圆点，标准使用层级，深度使用搜索。
- 研究模式：广度使用分支，深度使用搜索。
- 关联关系：链接图标。

记录详情的左侧层级轨使用同一品牌色递进：轻量为 2px 弱色、标准为 3px 中色、深度为 4px 主色；记录等级不借用成功、警告或危险色。

### 3. 状态

状态使用“状态图标 + 文字 + 语义色”。只有状态可以使用弱背景和小圆角，禁止胶囊形。

| 状态或提示 | 适用记录 | 图标 | 色调 |
| --- | --- | --- | --- |
| Todo / Inbox / 待处理 | 任务、想法及尚未开始的记录 | 圆点环 | 中性 |
| Doing / 进行中 / 待研究 / 待跟进 | 任务、研究、已决定待落实的问题 | 时钟 | 提醒 |
| Done / 已完成 / 已处理 | 任务、想法、研究、问题、风险、工作记录 | 圆形勾选 | 完成 |
| 已归档 / 不再适用 | 研究、历史问题、历史风险 | 归档 | 中性 |
| 阻塞提示 / 风险与后续 | 需要关注的协作记录 | 警告三角 | 提醒 |
| Abandoned / 失败 | 放弃的任务或失败记录 | 圆形叉号 | 危险 |

状态文案描述记录本身，不描述执行者或后台能力。使用“进行中”“待跟进”“等待处理”等中性表达。

### 4. 冗余信息

- 任务卡片不重复显示所在列已经表达的状态。
- 工作记录目录默认不重复显示全部为 Done 的状态；只在非完成状态时展示。
- 卡片左侧状态轨与状态图标不能同时使用多种颜色表达同一件事。
- 单行最多展示两个元信息标记；其余放入详情。
- Ready、更新时间、当前版本、完成时间和计数属于上下文信息，不使用状态 Tag。
